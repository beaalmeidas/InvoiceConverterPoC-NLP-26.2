# Resultados

Os arquivos existentes foram preservados nos seus caminhos para manter as
referências dos notebooks e os resultados dos experimentos.

| Caminho | Conteúdo |
|---|---|
| `img_*.json`, `img_*.md`, `img_*_table_*.html`, `imgs/` | Saídas do `main.py` e representações usadas nos experimentos |
| `qwen-html/`, `qwen3-html/` | Resultados dos experimentos Qwen |
| `gemma-html/`, `gemma-md/` | Resultados dos experimentos Gemma |
| `extracao/`, `extracao_pdf/` | Extrações de outros fluxos/execuções |
| `comparacoes/` | Comparações baixadas do Colab |
| `validacao/` | Artefatos de validação |
| `danfes_sinteticos/` | PDFs e XMLs gerados por `scripts/danfe.py` |
| `*.zip` | Pacotes de resultados |

Diretórios de execuções e ZIPs são ignorados pelo Git; nenhum arquivo local
foi removido. Exemplos já rastreados continuam versionados. Confira os resultados
contra a entrada original antes de utilizá-los.
